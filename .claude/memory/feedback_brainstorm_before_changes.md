Always use `superpowers:brainstorming` before making changes — even tasks that look straightforward (renames, refactors, config updates).

**Why:** User installed the superpowers plugin specifically for this workflow. Jumping straight to execution bypasses the intent-clarification and tradeoff-surfacing that brainstorming provides, which the user finds frustrating.

**How to apply:** No matter how simple or obvious the task seems, invoke `superpowers:brainstorming` first. The skill exists to catch things that "mechanical" execution misses — and the user wants that check every time.
